# Yarrowpine Developer Cheatsheets

*2 printable quick-reference sheets — regular expressions and HTTP/REST APIs — A4 and US Letter (free edition)*

Independent product by Yarrowpine Studio, not affiliated with, endorsed by, or sponsored by any owner of a name mentioned here.

## What you get

- **Regular expressions** and **HTTP and REST APIs**, one landscape page each, in **A4** and **US Letter**
- An all-in-one PDF (2 pages) for each paper size

## Printing tips

Print at **100% / "Actual size"**, landscape. Colour or black-and-white both work.
